API

For scripts: the calls this node answers over HTTPS

Every call is POST /call/<interface>.<Method> with its parameters as a JSON object, and an API token as Authorization: Bearer …. Each needs a role; calls your role cannot make are greyed out.

  • Errors keep their Varlink name, parameters and a message: 400 for a malformed call, 401 without valid credentials, 403 when the role does not allow it.
  • Streaming calls take ?more=true and answer with a JSON text sequence (application/json-seq) until the connection closes.
  • Tokens and sessions: scripts use a token; this page's own session also sends the X-Sparewall-Request header, which a cross-site form cannot.
